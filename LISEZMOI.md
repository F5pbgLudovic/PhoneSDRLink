# PhoneSDRLink (F5PBG) — notes de projet

Application Android (APK) qui reprend les fonctions de réception de SDRLink, sans la télécommande du poste. Notice d'utilisation et d'installation : [README.md](README.md).

## Où est quoi

* Sources : `app\src\main\java\fr\f5pbg\phonesdrlink` (Java pur, un seul écran).
  * `MainActivity` : écran, WebView, état (fréquence, mode), scan, son (focus audio, appel, volume du téléphone), REC, verrou, zoom du spectre, mises à jour.
  * `Store` : tous les réglages (`settings.ini`, même format que SDRLink PC : un export de SDRLink PC s'importe : SET › Importer des réglages…, détail dans le README, essayé avec un vrai fichier le 4 nov. 2026 : 166 favoris, 5 listes, 3 mémoires, 2 profils), favoris, mémoires, profils de scan.
  * `PlayService` : service de premier plan (notification, verrou processeur + Wi-Fi) lancé au démarrage, arrêté à la fermeture : son fluide écran éteint. `MainActivity` n'appelle plus `web.onPause()` ni n'abandonne le focus audio à la mise en pause.
  * `Finder` : annuaires websdr.org / KiwiSDR / ReceiverBook. `Dlg*` : fenêtres (WEBSDR, favoris, recherche, mémoires, scan, SET, clavier). `CheckList` : liste à cases. `Ui`, `FreqBar`, `Lang`. `ShareLink` : lien de partage `https://bt0r.github.io/PhoneSDRLink/s/?u=&f=&m=[&bw=][&d=]` (`ShareLink.WEB_BASE` + intent-filter https du manifeste ; page GitHub Pages `docs/s/index.html`, publiée depuis le dossier `docs` ; `phonesdrlink://tune?` aussi accepté) (Java pur, tests JUnit dans `app\src\test`, `gradle testDebugUnitTest`) ; bouton et réception dans `MainActivity` (`shareButton`, `handleShareIntent`).
* **Décodeurs (1.9)** : `DlgDecoder` (fenêtre, panneaux de réglages CW et RTTY), `Decoders` (JNI), `Ft8Engine` (FT8 et FT4), `RadeEngine` (FreeDV RADE, AudioTrack, bascule du son), `TextEngine` + `CwEngine` + `RttyEngine` (Java pur, fil à part) ; bloc « décodeurs numériques » de `MainActivity` (journal coloré, écran principal, FreeDV auto, cleanTemp) ; `bridge.js` : `L.decStart(rate)` / `L.decStop()` (copie du son brut vers Java). Code natif : `app\src\main\cpp` (CMake ; `ft8lib` = ft8_lib MIT, `rade` = radae_nopy BSD, `opus` = extraits d'Opus BSD avec les poids FARGAN, `sdrdec_ft8.c`, `sdrdec_rade.c`, `sdrdec_jni.c`) ; licences : `THIRD-PARTY-NOTICES.md`. Banc d'essai PC des décodeurs de texte : `tools\bench` (sans téléphone).
* `app\src\main\assets\bridge.js` : pont JavaScript injecté dans chaque page (dérivé de `WebSdrBridge.cs` de SDRLink) : détection du type de WebSDR, lecture/réglage fréquence et mode, démarrage automatique du son, chaîne audio (notch automatique, réducteur de bruit, gain), volume de la page, REC MP3, zoom du spectre, viewport 1000 px, désactivation de la reconnaissance vocale (qui faisait tomber UberSDR).
* `assets\lang\xx.txt` : 23 langues (anglais → traduction, comme SDRLink). `assets\default-favorites.txt` : favoris de départ (liste « HF »). `assets\lame.min.js` : encodeur MP3 lamejs (LGPL-3.0).
* Chaîne de compilation : `toolchain\` (non versionnée) ← `tools\install-toolchain.ps1` (JDK 17, Gradle, SDK Android, **NDK 26.1.10909125, CMake 3.22.1**). Compiler : `.\build.ps1`. Le code natif est compilé par Gradle (externalNativeBuild) ; abiFilters arm64-v8a + armeabi-v7a, FreeDV RADE seulement en arm64-v8a.
* Signature : `phonesdrlink.jks` (mot de passe `phonesdrlink`), **non publiée** : à garder dans la sauvegarde ; sans elle une mise à jour ne s'installe plus par-dessus l'ancienne version.

## Règles de travail

* Demander à F5PBG avant d'ajouter une fonction de SDRLink qu'il n'a pas citée.
* Publier (GitHub, release) seulement sur demande.
* Tout nouveau texte : `Lang.T("français", "English")`, puis ajouter la ligne `English<TAB>traduction` aux 21 fichiers de `assets\lang` (attention aux espaces de fin de clé).
* Textes traduits en 21 langues : écrire un script PowerShell (tableau langue → traductions) avec l'outil Write, l'exécuter par `Invoke-Expression ([IO.File]::ReadAllText(chemin,[Text.Encoding]::UTF8))` (Python absent ; ne pas écrire d'accents dans une commande directe), et ne pas ajouter une clé déjà présente. (voir README, « Outils de mise au point ») ; contrôler le premier plan (`dumpsys window | grep mCurrentFocus`) avant tout `input tap`, F5PBG utilise parfois le téléphone en même temps.
